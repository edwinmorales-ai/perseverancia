¿Qué es Open MCT y cómo le mostramos la telemetría de Percy?

Open MCT es el tablero de control que la NASA usa en una página web: junta en pantallas los datos que mandan sus naves y robots para verlos en vivo, en gráficas y tablas.

Por dentro tiene un núcleo pequeño al que se le enchufan piezas (plugins). Cada fuente de datos, cada tipo de gráfica y cada pantalla es una de esas piezas. Para mostrar a Percy (Perseverance) hay que escribir una pieza más.

  • Plugin: pieza que se enchufa al núcleo.
  • Proveedor: quien entrega los datos.
  • Pedido (request): «dame lo que pasó antes».
  • Suscripción (subscribe): «avísame en vivo».
  • archivo:línea: dónde está cada cosa en el código.

Las 5 piezas para conectar a Percy

Con estas cinco piezas, Open MCT ya sabe qué es Percy, dónde mostrarlo y de dónde sacar sus datos. La gráfica viene incluida: es un plugin de serie (src/MCT.js:285) y aparece sola cuando un objeto tiene un número para dibujar (src/plugins/plot/PlotViewProvider.js:39).

Cómo conectamos Percy

Es un plan: no se instaló nada. Aclaración honesta: la NASA no publica la telemetría de ingeniería de Perseverance en vivo. «Percy» aquí es nuestro rover simulado, que ya calcula su telemetría en src/ui/telemetry.js.

  1. Elegir qué medir. De la telemetría del simulador, los valores numéricos: velocidad (cm/s), recorrido (m), rumbo (°), cabeceo y alabeo (°), posición x/z (m) y muestras. El estado y lo de Ingenuity son texto: van en una tabla, no en una gráfica (Open MCT solo ofrece gráfica si hay un número, src/api/telemetry/TelemetryAPI.js:322). La energía es un valor fijo, no una medición.
  2. Transmitir desde el simulador. En update() de src/ui/telemetry.js, que ya corre 10 veces por segundo, mandar cada lectura por un canal del navegador: new BroadcastChannel('percy-telemetria').postMessage({ utc: Date.now(), velocidad, rumbo, … }). La hora va en utc porque es la clave del eje horizontal (src/plugins/plot/configuration/XAxisModel.js:103).
  3. Hacer una página de control (por ejemplo control.html) servida desde el mismo sitio que el simulador, que cargue Open MCT e instale el sistema de tiempo UTC y el conductor de tiempo, igual que el ejemplo (index.html:119 y index.html:131). Cargar Open MCT necesita descargarlo (npm o un CDN): eso se hará más adelante y solo con permiso.
  4. Escribir el plugin de Percy con las piezas 1 a 4: tipo percy.medicion, raíz percy:rover, una carpeta con una medición por cada valor, y en cada una telemetry.values con utc (domain) y el valor (range).
  5. Agregar el proveedor de telemetría (pieza 5): subscribe escucha el canal y pasa cada lectura a la gráfica; request devuelve lo guardado en un búfer de los últimos minutos para el historial.
  6. Instalar y arrancar: openmct.install(PercyPlugin()) y openmct.start(). En el árbol aparece «Percy › Velocidad» con su gráfica, que viene de serie.
  7. Probar con dos ventanas lado a lado (no pestañas): una pestaña oculta pausa la simulación y la gráfica se quedaría quieta.
  8. Para una misión de verdad, cambiar el canal del navegador por un WebSocket con un servidor, que es lo que hacen las misiones reales.
Para curiosos: cómo se vería el plugin (esquema) 
function PercyPlugin() {
  return function install(openmct) {
    openmct.types.addType('percy.medicion', { name: 'Medición de Percy', cssClass: 'icon-telemetry' });
    openmct.objects.addRoot({ namespace: 'percy', key: 'rover' });
    openmct.objects.addProvider('percy', { get: (id) => /* carpeta o medición */ });

    const canal = new BroadcastChannel('percy-telemetria');
    openmct.telemetry.addProvider({
      supportsSubscribe: (objeto) => objeto.type === 'percy.medicion',
      subscribe(objeto, avisar) {
        const alLlegar = ({ data }) => avisar({ utc: data.utc, value: data[objeto.identifier.key] });
        canal.addEventListener('message', alLlegar);
        return () => canal.removeEventListener('message', alLlegar);
      },
      supportsRequest: (objeto) => objeto.type === 'percy.medicion',
      request: (objeto, { start, end }) => /* lecturas guardadas entre start y end */
    });
  };
}
